# MORELY-V3-MD
Bot WhatsApp Morely MD V1, kamu diwajibkan mengisi Apikey terlebih dahulu, Jika tidak mengisinya maka bot tidak akan berfungsi dengan baik.  Tidak disarankan menginstal bot ini di termux atau panel yang tidak mempunyai kelengkapan ffmpeg, imagemagick, webp atau panel yang tidak support express.js  Menggunakan 95% fitur dari RestApi
